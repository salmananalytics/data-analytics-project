# Retail Sales Data Analyst Project

## 📊 Project Overview

This project focuses on analyzing retail sales data to identify sales trends, customer behavior, product performance, and overall business performance.

The goal of this project is to transform raw sales data into meaningful insights that can help businesses make better data-driven decisions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- SQL
- Power BI
- Data Analysis
- Data Visualization

## 🔍 Key Analysis

- Sales and profit analysis
- Product and category performance
- Customer and regional analysis
- Monthly and yearly sales trends
- Top-performing products
- Profitability analysis
- Business performance insights

## 📈 Key Insights

The analysis helps identify:
- High-performing products and categories
- Sales trends over time
- Profitable and less profitable segments
- Customer and regional performance
- Areas where business performance can be improved

## 📁 Project Files

- `Retail_Sales_Data_Analyst_Project.pptx` – Project presentation containing analysis, visualizations, and insights.

## 🎯 Objective

To demonstrate practical Data Analyst skills including data analysis, business problem-solving, visualization, and presenting actionable insights.
